Totals for Lectures 1–7: 16 lessons, 67 quiz questions, 95 ungraded in-text “try it yourself” questions, 32 practice problems.

Every lesson also has guided tasks before each visualizer and an “In practice / in real life” section (libraries such as Timsort, introsort, `std::nth_element`, B-trees, RadixSort on GPUs; applications such as percentiles, external sorting, schedulers). Additional figures beyond the table: `inversions` (L2 InsertionSort: each shift removes one inversion arc) and `rotation` (L7 red-black trees: animated rotation with subtrees α, β, γ).

Lecture 18 (“What’s next?”) has no lesson of its own but a wrap-up page, `#/kapanis` (`src/pages/WrapUpPage.tsx`): progress so far, the 17 lectures grouped into a toolbox of nine techniques (`src/content/wrapup.ts`, every lesson linked), the three “gems” of the Lecture 18 slides (linear programming and duality with the slides’ example, polynomial interpolation and Reed–Solomon codes, machine learning for algorithm selection), four try-it-yourself questions and where to go next. It is linked from the dashboard, the last lesson and the Sources page; its numbers are checked in `src/pages/wrapup.test.tsx`. Numbers quoted in the Lecture 8–17 content are re-checked in `src/content/later.test.ts`.

Lectures 1–6 also carry worked examples added after the first release: counting the steps of an all-pairs check (`l1-why`), best / worst / average case of InsertionSort with E[inversions] = n(n−1)/4 (`l2-insertion`), stability and extra memory of MergeSort (`l2-mergesort`), explicit Θ witnesses for n²/2 − 3n (`l2-asymptotics`), a recurrence outside the Master Theorem, 2T(n/2) + n log n = Θ(n log² n) (`l3-master`), the “Big-O inside the induction” trap (`l3-substitution`), equal keys and three-way partitioning (`l5-quicksort`) and an indicator-variable warm-up (`l5-expected`). Their numbers are re-checked in `src/content/content.test.ts`.

Lectures 7–17 got the same treatment: insertion order and BST shape (`l7-bst`), doubling a hash table and amortized cost (`l8-hashing`), bipartiteness with BFS layers (`l9-graphs`), a topological order from finish times and back edges (`l9-dfs`), the condensation DAG (`l10-scc`), parent pointers and the shortest-path tree (`l11-dijkstra`), edge order and early stopping (`l12-bellman-ford`), the diagonal test and transitive closure (`l12-floyd`), edit distance (`l13-lcs`), why ratio-greedy fails for 0/1 knapsack (`l13-knapsack`), counterexamples to wrong greedy rules (`l14-greedy`), the cycle property (`l15-mst`), why reverse edges are needed (`l16-maxflow`) and deferred acceptance when everybody agrees (`l17-stable-matching`), plus a second practice problem per lesson (a Huffman quiz question in `l14-huffman`). Every number is re-checked in `src/content/later.test.ts`.

A second round filled the remaining Lecture 1–7 lessons: Karatsuba’s real multiplication count with carries and Gauss’s three-product complex multiplication (`l1-karatsuba`), binary InsertionSort (`l2-insertion`), the probability that random-pivot QuickSort hits its worst case, 2ⁿ⁻¹/n! (`l5-quicksort`), CountingSort with prefix sums and the choice of base (`l6-bucketsort`), nearly sorted input (`l6-compare`), node counts for a given black height (`l7-redblack`) and heights under sorted insertion (`l7-compare`). These are checked in `src/content/content.test.ts`.

A third round added worked examples to the three lessons that still had none: sorting a million 32-bit integers with comparison sorts vs RadixSort in bases 256 and 65536 (`l6-compare`), inserting 1…7 and then 8 into a red-black tree case by case (`l7-compare`) and encoding and decoding with the Huffman code of the notes, including the effect of a single bit error (`l14-huffman`), plus a third quiz question in each comparison lesson. They are checked in `src/content/content.test.ts` and `src/content/later.test.ts`.

The lessons with the fewest in-text questions then got two more each: nested or disjoint DFS intervals and BFS vs DFS for fewest-edge paths (`l9-dfs`), the weight that makes a cycle non-negative and the cost of n − 1 rounds (`l12-bellman-ford`), Floyd–Warshall vs n × Dijkstra on a sparse network and the max/min variant for widest bottleneck paths (`l12-floyd`). Numeric answers now also accept digit groups with spaces (“4 995 000”) and the typographic minus.

Finally, every lesson that still had four in-text questions got a fifth, attached to a section that had none (mostly the running-time sections): the recurrence T(n/4) + T(n/2) + n (`l3-substitution`), what the lower bound does not say (`l6-lower-bound`), 2m adjacency entries in BFS (`l9-graphs`), why the second SCC pass needs no sorting (`l10-scc`), the LCS table size (`l13-lcs`), presorted activities (`l14-greedy`), Kruskal with small integer weights (`l15-mst`), a flow and a cut of equal value as a certificate (`l16-maxflow`) and the n² − n + 1 proposal bound, checked over every preference profile for n = 3 (`l17-stable-matching`).

The last three lessons below five in-text questions then got two each: InsertionSort on sorted input and an adversary who reads the code of randomized QuickSort (`l6-compare`), the red-black height bound for n = 12 and the expected height of a treap (`l7-compare`), internal nodes of a full code tree and Huffman on Fibonacci frequencies (`l14-huffman`). The lessons with three quiz questions got a fourth (`l1-why`, `l6-compare`, `l7-compare`), so every lesson now has at least five in-text questions and four quiz questions.
